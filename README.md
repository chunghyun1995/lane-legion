# 레인 레기온 3D (Lane Legion)

좌우로 움직여 게이트로 병력을 불리고, 몰려오는 적 군단과 적장을 섬멸하는 브라우저 러너 디펜스 게임입니다.

Three.js/WebGL 기반의 로우폴리 3D 전장, 입체 병사·적장, 실시간 조명과 그림자를 지원합니다. 기존 저장 데이터와 전투 규칙을 그대로 사용하며, WebGL을 사용할 수 없는 기기에서는 2D 호환 모드로 실행됩니다.

▶ **플레이:** https://chunghyun1995.github.io/lane-legion/

## 조작
- 모바일: 화면을 좌우로 드래그
- PC: `←` `→` 또는 `A` `D`, 일시정지 `Esc` / `P`

## 규칙
길은 세 갈래 레인으로 나뉘어 있고, 어느 레인에 서 있느냐에 따라 할 수 있는 일이 다릅니다. 병사들은 자동으로 앞을 향해 화살을 쏩니다.

| 레인 | 나오는 것 | 하는 일 |
|---|---|---|
| 왼쪽 (파랑) | 병력 블록 `+N` `×2` `-N` | 통과하면 병력 증감. 쏘면 숫자가 커짐 (빨간 블록도 쏘면 줄어듦) |
| 가운데 (빨강) | 몬스터 무리 | 가까이 오면 레인을 벗어나 부대로 돌격. 처치 못 하면 병력 손실 |
| 오른쪽 (금색) | 특수능력 상자 | 화살로 부수면 아이템이 떨어짐 → 부대가 지나가며 먹어야 일정 시간 특수 무기 발동 |

**특수능력:** 🔥 화염 화살(피해 2배) · 🔱 삼연 사격(3방향) · ➶ 관통 화살 · ⚡ 속사 · 🛡 방패진(피해 절반) · 🌩 낙뢰(주기적 번개)

**상점 특수공격:** 메인 또는 결과 화면의 `상점 · 특수공격`에서 낙뢰 폭격을 60골드에 1회 구매할 수 있습니다. 구매 횟수는 저장되며, 전투 중 우측 상단 `⚡ 특수공격 ×N` 버튼을 누르면 1회를 사용합니다. 전방 사거리 안의 적과 상자에 광역 피해를 주며, 적장은 최대 체력의 30% 피해를 받습니다. 사용하지 않은 횟수는 다음 스테이지에서도 유지됩니다.

일반 화살은 검정색으로 표시되며, 명중 시 섬광·충격 링·3D 불꽃 이펙트가 발생합니다.

- 스테이지가 오를수록 맵 이동 속도가 빨라집니다.
- 스테이지 끝의 적장을 쓰러뜨리면 클리어. 골드로 화력·연사·시작 병력·특수 숙련을 업그레이드하세요.
- 진행 상황은 브라우저에 자동 저장되며, 시작 화면에서 **이어하기 / 새로하기**를 고를 수 있습니다.

## 구조
- `index.html` — 화면/메뉴 UI
- `core.js` — 게임 로직 (DOM 없음, Node에서도 실행 가능)
- `main.js` — HUD, 입력, 저장, 2D 호환 렌더링
- `render3d.js` — 3D 전장과 인스턴스 기반 병력 렌더링
- `vendor/three.min.js` — Three.js 0.160.1 (MIT, 라이선스 동봉). 외부 CDN 없이 실행

## 배포
GitHub Pages에서 `main` 브랜치의 루트 디렉터리를 게시합니다. 별도 빌드 없이 정적 파일로 실행되며, 브랜치 업데이트 시 기존 플레이 주소로 자동 배포됩니다.
