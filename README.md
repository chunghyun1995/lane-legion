# 레인 레기온 (Lane Legion)

좌우로 움직여 게이트로 병력을 불리고, 몰려오는 적 군단과 적장을 섬멸하는 브라우저 러너 디펜스 게임입니다.

▶ **플레이:** https://chunghyun1995.github.io/lane-legion/

## 조작
- 모바일: 화면을 좌우로 드래그
- PC: `←` `→` 또는 `A` `D`, 일시정지 `Esc` / `P`

## 규칙
- 병사들은 자동으로 앞을 향해 화살을 쏩니다. 병사가 많을수록 화력이 강해집니다.
- 파란 게이트(`+N`, `×2`)는 병력을 늘리고, 빨간 게이트(`-N`)는 병력을 줄입니다.
- 게이트를 쏘면 숫자가 커집니다. 빨간 게이트도 충분히 쏘면 파랗게 바뀝니다. (적을 쏠지, 게이트를 키울지 선택!)
- 적과 부딪히면 병사가 줄어듭니다. 병력이 0이 되면 패배.
- 스테이지 끝의 적장을 쓰러뜨리면 클리어. 얻은 골드로 화력·연사·시작 병력을 업그레이드하세요.
- 진행 상황은 브라우저에 자동 저장됩니다.

## 구조
- `index.html` — 화면/메뉴 UI
- `core.js` — 게임 로직 (DOM 없음, Node에서도 실행 가능)
- `main.js` — 캔버스 원근 렌더링, 입력, 저장
